# TO_SIMO_DO

- **GitHub Pages Configuration**: Once you push the `website` directory to GitHub, go to your repository Settings > Pages. Choose to deploy from GitHub Actions (which is often easiest for Vite) or use an action to build and deploy the `website/dist` folder to the `gh-pages` branch. You can find Vite deployment guides here: https://vitejs.dev/guide/static-deploy.html#github-pages.
- **App Store Submission**: When submitting SafeSpot to the App Store, you can link to:
  - **Support URL**: `https://<your-github-username>.github.io/Where-Is-It-/support.html` (adjust the path to match your repo name).
  - **Marketing URL**: `https://<your-github-username>.github.io/Where-Is-It-/index.html`
  - **Privacy Policy URL**: `https://<your-github-username>.github.io/Where-Is-It-/privacy.html`
